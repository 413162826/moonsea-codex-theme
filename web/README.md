# 月海官网

月海 Codex 主题的 Sites 站点，包含公开主题墙、自动下载入口、聚合流量接口和仅员工可见的数据页。

## 隐私边界

- 月海运行期间每 5 分钟记录随机安装标识、月海版本、操作系统、架构和上报时间；助手与月海 Codex 进程绑定，退出后停止。
- 上报负载不包含 Codex 账号、邮箱、提示词、项目名称、文件路径、IP 地址、原始 User-Agent 和壁纸内容，业务数据库也不保存 IP。
- 网站流量只按日期、公开页面和下载系统聚合，不使用 Cookie 或访客标识。
- `/admin` 使用 ChatGPT 登录，并在服务端校验管理员邮箱白名单。

## 本地开发

```bash
npm ci
npm run dev
npm test
```

修改 `db/schema.ts` 后运行 `npm run db:generate`，生成并检查 D1 迁移再发布。
