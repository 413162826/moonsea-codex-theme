# 安装与首次使用

## Windows

1. 在官网点击“下载”。
2. 运行 `Moonsea-Codex-Windows-x64-Setup.exe`。
3. 安装完成后，从桌面打开“Codex 月海版”。

## macOS

1. 在官网点击“下载”。
2. 解压 `Moonsea-Codex-macOS.zip`。
3. 右键打开 `Install.command`。
4. 从生成的入口打开“Codex 月海版”。

## 应用主题

保持 Codex 月海版打开，进入官网主题墙。页面显示“Codex 已连接”后，选择任意壁纸并点击应用，主题会立即作用于当前窗口。

月海版使用独立副本和独立用户目录，不修改官方 Codex 应用和官方用户资料。
