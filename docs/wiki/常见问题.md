# 常见问题

## 官网显示 Codex 未连接

确认打开的是“Codex 月海版”，等待启动完成后在官网点击重试。

## 点击应用后提示需要升级

当前月海助手版本过旧。打开月海助手完成更新，再回到官网应用主题。

## 下载了错误的系统版本

重新打开官网点击“下载”。无法识别系统时，下载页会要求手动选择 Windows 或 macOS，不会默认下载错误安装包。

## 系统已经关闭动画，为什么特效开关不能打开

月海尊重系统“减少动态效果”设置。关闭系统的该设置后，月海会恢复之前保存的特效选择。

## 月海会上传什么数据

月海运行期间会在启动时及之后每 5 分钟上报随机安装标识、版本、操作系统、架构和上报时间，用于统计安装设备与活跃趋势。助手与月海 Codex 进程绑定，退出月海后停止。上报负载不包含账号、邮箱、提示词、项目名称、文件路径、IP 地址、原始 User-Agent 或壁纸内容，业务数据库也不保存 IP。

官网只统计按日期和页面聚合的访问次数，不使用 Cookie 或访客标识。
