# 月海 Codex 主题

月海为 Codex 提供免费渐变壁纸和 Pro 精选壁纸。安装一次月海助手后，可以直接在官网选择并应用主题。

## 开始使用

1. 打开[月海主题官网](https://moonsea-codex-theme.suguowen5.chatgpt.site)。
2. 点击“下载”，网站会自动识别 Windows 或 macOS。
3. 完成安装并打开“Codex 月海版”。
4. 回到官网主题墙，选择壁纸并点击应用。

## 功能

- 免费渐变壁纸与 Pro 精选壁纸
- 界面透明度、背景亮度与背景清晰度
- 正文增强
- 一键开启或关闭全部交互特效
- 自定义本地壁纸
- 助手内自动更新
